Walnuts
=======

Cone-beam micro-CT scans of 42 walnuts, each measured from three source
positions, with high-quality reference reconstructions (Der Sarkissian et al.,
"A cone-beam X-ray computed tomography data collection designed for machine
learning", Scientific Data, 2019). It is distributed on Zenodo.

Download
--------

.. code-block:: bash

   python LION/data_loaders/walnuts/download.py

It writes ``LION_DATA_PATH/raw/walnuts``.
