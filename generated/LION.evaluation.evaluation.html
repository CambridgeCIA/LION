LION.evaluation.evaluation¶

Evaluating a reconstruction method on a test set.

Evaluation is the standard evaluation of one problem, like an Experiment: the test data (an experiment’s split, or a dataset), the operator, the metrics (PSNR, SSIM, HaarPSI) and how their range is set. Its run(method) scores every test sample and gives a test record:

  • name, method (what was run, e.g. a model’s spec and weights hash);

  • evaluation (this evaluation’s spec), data (the test data’s record, LION.data_loaders.data_record), metrics (their specs; and whether higher_is_better), data_range;

  • scores: the sample ids and, per metric, the score of each sample;

  • summary: per metric mean, std, median, q25, q75, min, max; seconds_per_sample; environment.

Records are LIONParameter``s, saved as plain JSON in ``save_folder (by default $LION_RESULTS_PATH/evaluations). Running the same method on the same evaluation again reads the saved record instead of recomputing it.

The functions work on their own too: scores (one method on some data), summary, table (records as markdown, LaTeX or CSV).

Bases: object

The standard evaluation of one problem (see the module docstring).

experiment: its split is the test data, and its geometry gives the operator; or dataset (and operator) for data set up without an experiment. metrics: {name: metric}, by default PSNR, SSIM and HaarPSI. normalisation: the range the metrics use: "dataset" (the test samples’ minimum and maximum, the same for every method; default), "sample" (each target’s own range), (min, max), or a LION Normalisation. samples: all (None), n (evenly spaced over the test set) or a list of sample IDs. save_folder: where records are saved and reused (default $LION_RESULTS_PATH/evaluations; None without it). device: where methods run (default LION’s).

run(x, name=None, *, save=True, allow=(), verbose=1)[source]¶

Score x (a model, a model’s file, a solver, a reconstructor or a function f(y, operator); see LION.evaluation.method) on every test sample. Returns its test record, saved in save_folder; a record saved before for the same method and evaluation is read instead. allow: modules outside LION a model file may name (e.g. your own solver). verbose: 1 (default) shows a progress bar over the test samples; 0 nothing.
