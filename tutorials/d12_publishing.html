Publishing and reproducing¶

LION.package.publish writes a trained model as a package: one folder with everything needed to use it, test it and train it again, from the records LION saved with it (Saving, loading and records). Someone with the folder and the data then loads it, builds its pieces, or trains it again.

Previous: Evaluation and comparison. Next: Extending LION.

Needs a GPU and the processed LIDC-IDRI data in LION_DATA_PATH. Publishing also needs LION’s code committed and pushed (it records the commit).

Note

The models trained in these tutorials are toys: a few epochs on a few slices, to show how LION is used, so their results are poor (often worse than FDK). Trained as their papers train them (many epochs, all the data), they do what the papers report.

A model to publish¶

Trained by a LION solver on a LION experiment, so that everything about it is recorded:

import tempfile
from pathlib import Path

import torch
from torch.utils.data import DataLoader, Subset

from LION.experiments import ct_experiments
from LION.models.post_processing.FBPConvNet import FBPConvNet
from LION.optimizers.SupervisedSolver import SupervisedSolver

experiment = ct_experiments.LowDoseCTRecon()
training = Subset(experiment.get_dataset("train"), range(40))
training_loader = DataLoader(training, batch_size=4, shuffle=True)

folder = Path(tempfile.mkdtemp())
model = FBPConvNet(experiment.operator_params)
solver = SupervisedSolver(
    model, torch.optim.Adam(model.parameters()), torch.nn.MSELoss()
)
solver.set_training(training_loader)
solver.set_saving(folder, "FBPConvNet")
solver.train(2)
solver.save_final_results()

Publishing¶

publish(model_file, folder, evaluation=...): the evaluation (optional) is run on the model and its test record included. The folder must be new (or empty).

from LION import package
from LION.evaluation import Evaluation

evaluation = Evaluation(experiment, samples=10)
published = package.publish(
    folder / "FBPConvNet", folder / "package", evaluation=evaluation
)
print(sorted(p.name for p in published.iterdir()))

['README.md', 'data', 'environment.txt', 'experiment.json', 'model.json', 'model.pt', 'package.json', 'solver.json', 'test.json']

The package holds the model file, the experiment, which samples it was trained and validated on, the training record, the test record, the environment, every citation, and a model card (README.md) with the code to use and train it again:

print((published / "README.md").read_text())

# FBPConvNet trained on LIDC-IDRI: Low dose full angular sampling experiment

Published on 2026-11-10 with LION 0.2.0 (commit 2162661184). Generated from the package's records (`package.json` lists them); edit it freely, it isn't checksummed.

## The model

- `LION.models.post_processing.FBPConvNet.FBPConvNet`, 34,556,033 parameters.
- The weights: final, after epoch 2.

## The problem

- Experiment: `LION.experiments.ct_experiments.LowDoseCTRecon`, "Low dose full angular sampling experiment".
- Dataset: LIDC-IDRI (`LION.data_loaders.LIDC_IDRI.LIDC_IDRI`).
- Geometry: fan beam, 360 angles, detector 1x1024, image 1x512x512.
- Noise: I0 11000, sigma 5, sigma_blur 0.3015, model physical, detector energy_integrating, mass_attenuation 0.1837, min_counts 1.0 (seed 0).

## Training

- Solver: `LION.optimizers.SupervisedSolver.SupervisedSolver`, loss `MSELoss`; optimizer `Adam` (learning rate 0.001).
- Data: the train data, 40 samples from 8 groups; batch size 4, shuffled.
- 2 epochs of 2; at the end, training loss 0.03577.
- Seed 0; initial weights made again from the random state saved with the model.
- Trained with LION 0.2.0 (commit 2162661184), Python 3.12.15, torch 2.13.0, on Quadro RTX 6000, Quadro RTX 6000, Quadro RTX 6000, Quadro RTX 6000 (CUDA 12.9); deterministic: no, so runs on a GPU differ slightly.

## Test

On the test data (10 samples from 10 groups), metrics over the range [0.0, 2.89096999168396] (`test.json`):

| Method | PSNR | SSIM | HaarPSI |
|---|---|---|---|
| FBPConvNet | -0.9934 ± 5.2138 | 0.0463 ± 0.0220 | 0.0618 ± 0.0306 |

## Training it again

In the package's folder, from its files alone:

```python
from LION.package import train_again

model = train_again(".", "retrained")
```

To change something first (the model, the experiment, the solver, the optimizer, the training):

```python
from LION.package import load, train_again

package = load(".")
package.training.epochs = 2 * package.training.epochs  # for example
model = train_again(package, "retrained")
```

### Step by step

```python
import pathlib

import torch
from torch.utils.data import DataLoader, Subset

from LION.data_loaders.data_record import read_record
from LION.experiments.ct_experiments import Experiment
from LION.models.LIONmodel import LIONmodel
from LION.optimizers.LIONsolver import LIONsolver
from LION.optimizers.training_record import read_training_record

record = read_training_record("solver.json")


def data(file):
    """The data a record describes, made by its experiment."""
    record = read_record(file)
    made = Experiment.instantiate(file).get_dataset(record.split)
    subset = getattr(record, "subset", None)
    return made if subset is None else Subset(made, subset.indices)


model = LIONmodel.instantiate("model", initial_weights=True)
solver = LIONsolver.instantiate(
    "solver.json", model, device=torch.device("cuda")  # where it was trained
)
t = record.train
solver.set_training(
    DataLoader(
        data("data/training.json"),
        batch_size=t.batch_size,
        shuffle=t.shuffle,
        drop_last=t.drop_last,
    )
)
pathlib.Path("retrained").mkdir(exist_ok=True)
solver.set_saving("retrained", "model")
solver.train(record.epochs.done)
solver.save_final_results()
```

Training again¶

train_again trains the model again from the same start, on the same data, with the same solver, seed and epochs: the published model again (exactly on a CPU; on a GPU, to about 1e-3).

Changing a recorded argument first trains a variant: anything not changed stays as recorded. E.g. another activation (a new model, new random weights):

p.model.model_parameters.activation = "LeakyReLU"
variant = package.train_again(p, folder / "variant")
print(type(variant).__name__)
